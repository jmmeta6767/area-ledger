# v1087 Shared workspace UX and accessibility

Base: main 74f1b95eef1152f8d4af336417f79db962a97713. Changes are limited to the canonical gateway client and its service worker cache version. Payroll and the separate AREA Maibab site are unchanged.

## Delivered behavior

- Shared navy/yellow/white controls and outline SVG icons, readable secondary text, visible keyboard focus, at least 44px button targets, and Thai font fallbacks. Printed documents retain their own styles.
- A company/project/local user-mode context appears on interactive pages. The profile retains its floating cover menu. Cloud status distinguishes local-only, offline, pending, syncing, conflict, error and confirmed sync; it reads the existing identity without creating a new one. The status opens the original backup/sync controls and updates without rerendering a draft. Cloud status does not imply Google Sheets is up to date.
- Foreman's home prioritizes daily expense entry, recent site records and projects. Owner's home prioritizes document review, accounting and reports. This is presentation using the existing local owner/foreman mode, not a new authenticated role/approval system.
- Dashboard, project and monthly-report charts include baht units, period, AREA Ledger source, calculation basis and the stored data update time in the Thai timezone. Accessible tables expose the same values. Empty charts say that no records are available. Legends distinguish left/right cash bars as well as color.
- A skip link, descriptive page titles, labelled modal dialogs, background isolation, Tab/Shift+Tab trapping, Escape and return-to-opener focus support keyboard use. Same-page draft rerenders retain focused field/selection. Selection buttons announce pressed state. Reduced motion is supported.

## Verification

Run `node tests/qa.cjs`, the repository Release QA suites and `node tests/workspace-ux-v1087.cjs` (Playwright plus axe-core 4.14.0). CI installs the isolated pinned runtime and uploads screenshots plus the JSON audit report.

- Chrome browser emulation: 320, 375, 390, 430, 768 and 1280 CSS pixels. Shared context, role home, no page horizontal overflow, keyboard modal behavior, offline status and draft preservation pass.
- axe WCAG 2 A/AA, 2.1 AA and 2.2 AA rule tags: 13 interactive pages at 390 and 1280, plus menu, backup dialog and foreman home at 390. Zero automated violations on the tested synthetic states.
- Chart checks preserve the synthetic 54,000-baht expense and verify units, period, source, update time and matching table values. Status tests distinguish synced, busy, pending and error without changing ledger transactions or creating a cloud key.
- Existing regression suites cover receipt scan error/retry, receipt totals, single save, reload, storage failure, repeat voice edits, Google sync selection/retry and account calculations. Existing iPhone keyboard and visualViewport suites cover draft retention and scroll access.

These are browser-emulation and automated/keyboard results, not testing on a physical iPhone or with VoiceOver/NVDA. They do not establish full WCAG 2.2 AA conformance. Real speech recognition, real receipt-provider calls and customer Google workbook writes are not performed by these isolated UI tests. No accounting formula, storage key, stored transaction or native Sheets exporter is changed by this release.
