# v1080 Repeated voice edits, shared app styling and clearer backups

Based on latest main 65d4d20e8ad844494c862a03a2193d7ad3966d6a.

- Repeat microphone sessions edit the current unsaved draft. `แก้ยอดเป็น 53,000`, `เปลี่ยนจำนวนเงินเป็น ห้าหมื่นสองพัน`, a bare amount, or `เปลี่ยนรายการเป็น ค่าแรงติดตั้งหลังคา` updates the relevant fields and preserves other fields. Explicit category or type commands still update the existing accounting categories. No voice command automatically saves a transaction.
- The latest transcript is shown only on its own draft. Invalid amount/date warnings survive unrelated corrections and are cleared when that field is corrected.
- Scan and microphone controls with their original handlers now sit directly below the amount, based on the previously circled scan/microphone reference.
- Interactive pages use the entry page navy/yellow colors, borders, controls and card radii. Printed document presentation is excluded from the shared screen styling.
- Backup groups separate downloadable JSON files, cloud syncing and restoring. Technical cloud operations and raw JSON are collapsed. Existing action names, elements, data formats, key handling and overwrite confirmations remain.

- Existing expense E2E at 320/375/390/430/768/1280, including explicit save-once, save-more, quota, offline/retry and reload.
- New `tests/ux-ui-v1080-e2e.cjs`: all 15 views at six widths, no horizontal overflow, shared header color, repeated field edits, original transaction count preserved, scan/mic placement and backup controls. Screenshots use synthetic data and browser emulation.
- Release regression suite includes storage/cloud sync, accounting, privacy and OAuth recovery contracts.
