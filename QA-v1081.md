# v1081 Short expense speech and repeat microphone lifecycle

Based on main 23ac510bcf06a963e8e20d3a30131c501708cfb0.

- `ค่าทราย 500`, Thai digits and `ค่าทราย ห้าร้อย` now yield amount 500, item ทราย and existing materials category ค่าของ. A generic expense prefix accepts short descriptions without requiring baht, while date/phone/quantity and malformed-money guards remain.
- Successful results finish with stop rather than abort. The next start waits for the browser end/disconnect event; repeated taps during release queue one next session on the same draft. The disconnected recognition instance is reused.
- A two-second missing-end watchdog releases a stuck engine and offers an explicit retry without losing the draft. Navigation, backgrounding, errors and manual cancellation abort and discard any queued start. Session generations reject prior callbacks.
- A delayed end event after a successful result does not rerender the form or steal focus. Pending restart has its own label rather than a misleading active microphone state.

Verification: main QA plus OCR/voice groups; ten repeated sessions with delayed WebKit end, queued taps, no abort on success, stale callback rejection, missing end and navigation cancellation. Browser emulation exercises real button clicks against a recognizer that refuses to restart while connected, verifies short expense parsing, field focus and all 15 views at six widths. Existing save-once/reload/offline/quota and accounting/storage contracts remain.

Physical iPhone Safari audio still requires a real device test; mocked callbacks cannot certify Siri/browser transcription quality. No automatic transaction save or storage identity change was introduced.
