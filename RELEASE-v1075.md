# v1075 — Category icon family

Add a consistent 24px line-icon family for expense and income categories, entry section headings, transaction rows and the main drawer. Materials, labor, guarantees, documents and rental equipment use distinct symbols and subdued blue/amber/violet/slate/teal backgrounds. Selected categories keep the Thai label, pressed state and check mark. BOQ and accounting receive distinct navigation icons.

Presentation only: category values, action keys, financial calculations and storage are unchanged. SVGs are inline, decorative and available offline; no remote icon/font dependency is added.

Validation: full production release QA (612 groups plus existing batch/single-save storage regressions); actual browser checks at 320/390/430/768px for selection, unchanged ledger and horizontal overflow; visually inspected mobile entry and drawer.
