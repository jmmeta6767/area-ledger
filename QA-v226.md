## Bugs fixed

1. Failed synchronous writes were still asynchronously saved into IndexedDB and
   could return as newer state on restart.
2. Duplicate IDs were silently rewritten by migration without fixing references.
3. Startup historical imports overwrote edited expense fields and could duplicate
   changed BOQ rows under the same ID. An intentionally empty database was reseeded.
4. A startup timeout could initialize data before IndexedDB finished loading.
5. Function-scoped `var go` in guarantee form shadowed navigation in other actions.
6. Transaction edits dropped hidden billing/receipt links and actual WHT metadata.
7. BOQ actual totals counted links from another project.
8. Forecast displays did not consistently include approved Variation; pending
   reductions and net-zero pending changes were absent from the action queue.
9. Closed/delivered projects still displayed missing/expired contract dates.
10. Timeline dates/status/replies and EOT quantities/approval references were under-validated.
11. Project deletion omitted Timeline, Variation, EOT and procurement references.
12. Batch OCR preselected guessed values; invalid amounts/projects could be saved.
13. Single-image OCR failures could leave busy state; late results could modify a new draft.
14. Ancestor `touch-action:none` prevented sheet touch scrolling; keyboard/landscape
    viewport was not followed consistently.
15. SW removed unrelated origin caches, could retrieve an old cache globally, and
    did not handle cache-write errors safely.
