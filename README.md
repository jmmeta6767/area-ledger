# AREA Ledger Master v107 — ศูนย์งานพัสดุและหนังสือราชการ

ต่อยอดจาก v106 โดยไม่เปลี่ยน localStorage `site-ledger-v1` หรือ IndexedDB `site-ledger-db`.

เพิ่ม:
- ศูนย์เอกสารและงานพัสดุ
- หมวด “หนังสือราชการ” แยกจากเอกสารธุรกิจ
- หนังสือ 12 กลุ่ม: นำส่งเอกสาร, Shop Drawing, ตัวอย่างวัสดุ, แจ้งเข้าดำเนินงาน/ส่งมอบพื้นที่, ปัญหา/อุปสรรค, ขอขยายเวลา, ส่งมอบงาน/ส่งงานงวด, แจ้งงานแล้วเสร็จ, ขอเบิกเงินค่างวด, ผลทดสอบ/ใบรับรอง, ตอบข้อสั่งการ, หนังสือทั่วไป
- เลขหนังสือ OUT-YYYY-0001 อัตโนมัติและแก้เองได้
- เรื่อง / เรียน / อ้างถึง / สิ่งที่ส่งมาด้วย / เนื้อหา / ผู้ลงนาม / สถานะ
- ดึงโครงการและเลขสัญญามาตั้งต้น
- Project Document Profile: หน่วยงานราชการ + ผู้รับหนังสือหลัก
- พิมพ์/บันทึก PDF ด้วยหัวกระดาษและโลโก้จากตั้งค่า
- schemaRev 107 พร้อม migration ข้อมูลเดิม
