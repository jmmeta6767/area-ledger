- Shared white surfaces, navy text, yellow primary actions, consistent headings, dialog close controls, readable field labels, selected states, table scrolling and visible focus.
- Inline validation announces the existing error, identifies the relevant field, opens its containing accordion and retains the draft. Business validation and write handlers remain unchanged.

- Project, profile and feedback forms retain sticky actions and focused-field visibility when a keyboard reduces the viewport, including short landscape screens. A Thai system-font fallback supports unavailable web fonts.

UI inspection does not alter financial collections. There are 204 observed action names with existing handler bindings; this is a binding check, not a claim that all 204 business actions were performed.
